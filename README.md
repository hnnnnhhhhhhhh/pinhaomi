# 拼好咪 · make cat cute

一个真实猫咪照片拼贴小应用。先进入封面，再从左侧素材库选择独立部件，放到右侧自由拼贴。所有素材可直接使用，随机挑选是可选操作。

直接打开 index.html。若浏览器限制本地图片导出，在此目录运行 `python3 -m http.server 8765`，打开 http://localhost:8765 。

## 构建运行版

使用 Node.js 运行 `node build.mjs`（或 `npm run build`）。构建会检查全部运行脚本的语法、107个部件的目录和素材引用，输出可独立使用的 `dist/`，并生成带SHA-256的build-manifest.json。无需安装依赖。`dist/index.html`是运行入口，分享时需保留整个dist目录，也可以解压「拼好咪-可运行版.zip」后打开其中的index.html。构建不访问Downloads，不包含素材生成脚本和源照片目录。

## 界面与风格

按照用户提供的 `/Users/hn/Downloads/拼贴/DESIGN (18).md`，采用暖米色纸面、黄色主按钮、小圆角素材容器及大字标。参考视频使用左侧素材、右侧组合的布局。封面图形填充真实猫毛照片；中文品牌字标按照新给的两张字体参考设计为胖圆、柔软的手作字形，英文固定为 make cat cute。

字标是独立生成的透明图片 `assets/pinhaomi-wordmark-v2.png`，不是用于猫咪部件的素材。所有可拼贴猫咪部件均直接来自用户照片，没有重绘或改色。字标的替代文字仍保留在语义标题中。

## 功能

- 107个真实照片部件，按脑袋、耳朵、眼睛、鼻子、嘴巴、身体、尾巴、蛋蛋分类。
- 直接点击或拖入画布；移动、缩放、旋转、翻转、置顶、置底、移除。
- 撤销最近40次操作；清空可撤销；方向键微调、Shift加速、Delete删除。
- 仅透明、白色两种底纸；导出1800像素宽PNG，透明底纸保留透明度。
- 作品不设取名输入框，导出文件名为拼好咪.png。本浏览器自动保存，兼容迁移旧版真实照片作品。返回封面不会清空作品。
- 手机素材栏改为横向浏览，点击添加或纵向拖入画布。

## 素材与文件

`catalog.js`：此前45个照片部件目录。`personal-data.js`：本批62个部件目录。`editor.js`：当前应用逻辑。`style.css`和`typography.css`：页面样式与定制字标。旧app.js不再由页面加载。

`build-assets.mjs`生成此前素材；`build-personal.mjs`生成本批素材和真实猫毛纹理。107个部件的轮廓蒙版现按裁切短边5%羽化（至少3原图像素），并通过feather-edges.mjs在裁切框四边加透明渐变，防止模糊轮廓在图片边界突然截断。仅处理Alpha，不模糊照片RGB。脑袋五官孔保留独立2.5像素羽化，避免强羽化重新显露原五官。原始JPEG直接内嵌；三个HEIC先由系统解码并缩放至长边1400像素，转换图保存在source-photos中。

同名带“2”的五张JPEG与不带“2”的文件哈希完全一致，已去重。本批照片共12张独立照片，提取62个部件；帽子遮住的耳朵不补画。详细来源见本批素材清单.md。

## 首页动效

字标采用笔画挤压咬合的胖圆字形，主标题最大宽度620像素，不加投影。鼠标悬停或手机轻触时，三个字分别显示固定搭配的小猫，取自封面下方三只完整拼贴，位置和大小固定；取消自动随机探头和轮换部件。下方三只咪每隔约3至6秒错开眨眼。系统减少动态效果开启时关闭漂浮和眨眼，离开首页、滚出视口或切换后台时暂停。未引入动画库。

「随机拼」按钮现使用相同随机组装逻辑，每次重新组合完整小猫，可以撤销回原作品。动态效果尚未由本机浏览器实测。
